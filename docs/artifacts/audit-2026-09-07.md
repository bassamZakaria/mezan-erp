# Mezan — full audit, 7 September 2026

Tree audited: `ab699559` on `bassamZakaria/sawfish` (0 commits behind `origin/main`).
Method: six specialist passes (sysadmin, security, product, accountant, performance, support),
every claim verified in code, not in docs. Gates at this tree: `pnpm typecheck`, `pnpm lint`,
`pnpm build` all green. Performance numbers come from a synthetic year‑three database
(20k invoices, 120k journal lines, 200k stock movements) on an M‑series Mac against an
unencrypted 88 MB file; a shop laptop with an encrypted 1–3 GB file is 5–15× slower.

## Verdict

The engine is sound and the shell is complete: 118 screens, 199 read surfaces answering smoke,
no placeholders, every list filter server‑wired, a correct GL posting core, a correct licence
state machine, and the best LAN transport code in the audit. **What is not sound is the
commercial layer that sits on top of it.** Today no packaged build can be licensed, no shop can
receive an update, the anti‑piracy check‑in enforces nothing and can brick a paying customer, and
a second machine on the shop LAN needs a consultant with a terminal to pair and to recover.
Underneath that, every SQLite call runs on the Electron main thread, so one slow report or the
daily backup freezes the host and every till together.

Nine items below are **blockers**: the product cannot be sold until they close. They are all
small in code. The largest of them (the vendor side of licensing) is a few days of work.

### Blockers

| # | Finding | Evidence | What the shop sees |

### Must

- **L‑6 Two screens, two verdicts.** The Connected Devices panel's licence notice reads `diagnoseDesktopEntitlements()`, which still reads the dev‑only `MEZAN_ENTITLEMENTS_JSON`, not the verified licence. A correctly licensed install shows `LIC-MISSING` «لا يوجد ترخيص على هذا الجهاز» there while the write gate says ACTIVE; an unlicensed one can be made to read `ENTERPRISE`. `index.ts:416,524`; `entitlements.ts:133‑161`; `licence-ipc.ts:113‑116`.
- **L‑7 A successful manual check‑in cannot lift read‑only until restart.** The write gate closes over the startup `const verdict`; the IPC handler writes `license-checkin.json` and nothing re‑reads it. «تم التحقق بنجاح» and posting still refused. `index.ts:438‑447`; `licence-ipc.ts:172‑176`. Same root cause: a licence that expires during a session that stays open for weeks is never noticed (`index.ts:360,447`).
- **L‑8 `CHECKIN_OVERDUE` tells the shop to renew a valid licence.** The banner branches on `state` only and renders «حتى تجديد الترخيص»; the correct Arabic sentence (`checkinMessageAr`, "connect to the internet") goes to `console.warn`. `LicenseBanner.tsx:36‑38`; `license-checkin.ts:151‑166`.
- **L‑9 `FINGERPRINT_MISMATCH` has no recovery path.** Replacement PC restores its backup, meets `MACHINE_NOT_BOUND`, sees one generic string «مرتبط بجهاز آخر … تواصل مع الدعم», and neither owner nor support can obtain the new fingerprint: no `--print-machine-fingerprint`, no panel, no log. `license.ts:196‑198`; `catalog.ts:27`.
- **L‑10 The rollback and check‑in guards are plain files the owner can delete.** `license-clock.json` and `license-checkin.json` sit unsigned in `userData`; a missing or unparseable file resolves to "no history"/"ok", not to TAMPERED. The comment claiming a monotonic cross‑check of `lastVerifiedAt` describes code that does not exist. `license.ts:181‑190`; `license-checkin.ts:29‑33,89`.
- **L‑11 The English error string is interpolated into the Arabic check‑in message** («تعذّر الوصول إلى خدمة التراخيص (no check-in endpoint configured)…»), and on a shipped install that is the only variant possible. `licence-ipc.ts:195`.
- **L‑12 Module entitlements gate no surface.** `createModuleGate` has zero call sites; `createBackend` takes no entitlements; the API serves `DEFAULT_ACTIVE_MODULES` (all 19) regardless of the licence; the verified `activeModules` reach only the LAN flag. A Core‑priced licence serves manufacturing, HR and assets. `packages/api/src/module-gate.ts:24`; `app.ts:213,860`; `desktop/index.ts:429`.
- **L‑13 The machine fingerprint shells out to `reg`/`ioreg` by bare name.** PATH‑resolvable; a pirate who reads one licensed machine's fingerprint can make others report it. `machine-fingerprint.ts:26,43`.

### Owner decisions on licensing

1. **7‑day online requirement vs "offline‑first".** `license-checkin.ts:34‑35` reads read‑only at 7 days and refuses to start at 30; `docs/archive/plan.md §8.0` and `.claude/stakeholders/context.md:45` say nothing may require connectivity. Both cannot be true in the sales deck. Recommendation: keep the check‑in, lengthen to 30/90, never close the app, and add a signed offline reprieve code support can read down the phone.
2. **Module pricing axis** (DEC‑15): if modules are priced, L‑12 must ship with the vendor side; if not, delete the module schema so nobody licenses what is not gated.
3. **Activation UX**: file import beside the database (cheapest, consultant‑driven) or an in‑app activation code that fetches the signed file (needs the vendor server). Recommendation: file import now, code later.

## 2. Patch updates — can a shop receive one?

**No. Not by any route.** Five independent gaps, each sufficient:

| # | Finding | Evidence |
|---|---|---|
| U‑1 | **Update public key is an empty constant with the same runtime‑env fallback as L‑1.** `verifyRelease` returns `NO_PUBLIC_KEY` → `rejected` on every check. | `updater.ts:48,254‑255` |
| U‑2 | **The release workflow never signs the SHA‑512 nor uploads `<version>.sig`**, though `electron-builder.yml:64‑68` says it must. The `.sig` fetch will 404 on every real release. | `.github/workflows/release.yml`; `updater.ts:265` |
| U‑3 | **Certificates are unbought** (Apple Developer ID, notarization key, Windows OV/EV), so `release.yml` fails at preflight and produces nothing; the updater refuses to run on an unsigned build. Known and documented. | `release.yml:57‑94`; `INSTALL.md §8.1` |
| U‑4 | **`MEZAN_UPDATE_FEED_URL` has no value.** Distribution channel unchosen. | repository variable |
| U‑5 | **What the owner sees today**: press «تحقق من التحديثات» → red `role="alert"` bar «تعذّر إكمال التحديث» across every screen, **no dismiss**, until restart. And the hook has no `.catch`, so an IPC rejection leaves the button silently dead. | `UpdateBanner.tsx:32‑41`; `update-hooks.ts:61‑66` |

### Must, once updates can flow

- **U‑6 The update signature does not bind the version.** Only the SHA‑512 is signed; the `.sig` path comes from feed metadata. An old, genuinely signed installer republished under a higher version passes both electron‑updater's semver check and the Ed25519 check: a downgrade attack from a compromised feed. Sign `version || channel || sha512`. `update-verify.ts:54`; `updater.ts:265`.
- **U‑7 One `.sig` for two Mac artifacts.** `primaryArtifactSha512` takes `files[0]`, but the build ships x64 and arm64 DMGs. Half the Mac fleet is refused or verifies the wrong bytes. `update-verify.ts:31‑35`; `electron-builder.yml:268‑270`.
- **U‑8 Manual install has no confirmation and ignores connected tills and business hours.** `install()` → `quitAndInstall()` at 1 pm; every till shows «تعذّر الوصول إلى الجهاز الرئيسي». The out‑of‑hours guard applies only to the launch‑time auto‑check. `UpdateBanner.tsx:82`; `updater.ts:223‑226,359‑363`.
- **U‑9 No schema version stamp and no rollback.** Migration is a regex over `CREATE TABLE IF NOT EXISTS` that ALTERs columns in; nothing writes `PRAGMA user_version`; an older build opens a newer database unchecked; the pre‑update backup exists but nothing surfaces "revert to the copy taken before this update". `packages/persistence/src/schema-sync.ts:19‑44`; `backup-hooks.ts:32`.
- **U‑10 Host/client version skew is a comment, not a check.** `/health` returns `{ok:true}` with no version; the client compares nothing. `create-backend.ts:1965`; `index.ts:100‑106`.
- **U‑11 Offline shops have no USB/manual update path** other than "install the new build by hand", and nothing documents the order (host first, then tills) in the product.
- **U‑12 `MEZAN_AUTO_UPDATE_ALLOW_UNSIGNED` is read from the environment on packaged builds.** Compile it out. `updater.ts:68,391`.
- **U‑13 Doc drift:** `MEZAN_AUTO_UPDATE_INSTALL=1` exists in `INSTALL.md §7` and in a test, and `updater.ts` never reads it.

## 6. What is genuinely solid

- **Licence state machine** (`license.ts:149‑238`): signature → clock rollback → notBefore → fingerprint → expiry/grace, pure, injected, fail‑closed; `usable` vs `canWrite` split honoured end to end. **Write gate** is one server‑side choke point that leaves reads, print, export and sign‑in open and answers in Arabic.
- **LAN transport**: TLS‑only with no HTTP fallback and a closed socket on failure; identity minted once and never re‑minted; SANs frozen so a DHCP move cannot change the fingerprint; pinning verified before a byte is written; never‑list before public‑list before authorizer; constant 404 body; per‑request own‑subnet check; bind default not `0.0.0.0`. **Seat model**: server‑derived identity, per‑user cap, reaping, disconnect revokes the real token, no "signed in but seatless" state.
- **Electron hardening**: `contextIsolation`, `sandbox`, `app://` scheme with `default-src 'none'`, navigation lock on every frame, webview refused. **Encryption at rest**: ChaCha20‑Poly1305 under a `safeStorage`‑sealed key, crash‑safe migration with backup‑first and row‑count verification, refuses to start without a keyring.
- **Release pipeline** fails closed at preflight, `forceCodeSigning`, `check-signed.mjs` re‑asks the OS, draft‑only releases, Linux honestly excluded. **Updater** never auto‑downloads or auto‑installs and refuses on an unproven own signature.
- **GL core**: the period gate is universal through `postJournalEntry` (structure → balance → accounts → period → VAT); reversal copies every dimension; numbering is gap‑free inside `BEGIN IMMEDIATE` with SAVEPOINT nesting; year‑end close previews and posts through one function; three‑state periods correct; `Money` string‑in only; invoice FX correct on both sides; bank reconciliation refuses unmatched lines; cheque GL coherent across all four transitions; reconciliation flags manual lines posted straight to a control account.
- **Persistence**: WAL + `busy_timeout` + one shared writer + async mutex; two tills confirming in the same second queue cleanly, no `SQLITE_BUSY`. `selectPage` is the right primitive; the sales‑invoice list path is the model (1 ms at 20k). ~80 indexes cover the filtered columns. Costing hot path is incremental.
- **UX done right**: restore confirmation requires typing the archive date; a damaged archive shows a pill, not a restore button; login lockout counts down the server's own wait; per‑row pending state on device rows; the `LIC-*` support codes exist (just unreachable).
