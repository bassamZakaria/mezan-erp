# Age rating answers

The app shows business records to a company's own staff. It has no chat, no
public posting, no web browser, no ads and no purchases.

| Question | Answer |
|---|---|
| Cartoon or fantasy violence | None |
| Realistic violence | None |
| Prolonged graphic or sadistic realistic violence | None |
| Violent themes | None |
| Profanity or crude humour | None |
| Mature or suggestive themes | None |
| Horror or fear themes | None |
| Sexual content or nudity | None |
| Graphic sexual content and nudity | None |
| Alcohol, tobacco or drug use or references | None |
| Simulated gambling | None |
| Medical or treatment information | None |
| Medical or wellness topics | None |
| Contests | None |
| Unrestricted web access | No — the privacy and deletion links open the system browser, not an in-app browser |
| Gambling (real money) | No |
| User-generated content shared with other users | No — documents are visible only to colleagues inside the same company account, under the permissions its administrator sets; nothing is public |
| Messaging and chat | No |
| Advertising | No |
| In-app controls (parental controls, age assurance) | No |

Expected result: **4+**.

## Google — IARC questionnaire

Category: **Reference, News, or Educational? No → Utility, Productivity,
Communication, or Other**. Every content question (violence, sexuality,
language, controlled substances, gambling, user interaction, shares location,
digital purchases) is **No**. Expected result: **Everyone / PEGI 3**.

**Target audience and content** (a separate Play section): **18 and over** only.
The app is for a company's employees; it is not designed for children and does
not appeal to them.
